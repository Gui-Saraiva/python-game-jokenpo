## ✊✋✌️ Rock Paper Scissors

This program simulates the classic Rock Paper Scissors game, where the user plays against the computer.

## 🧠 How it works:
- The user enters their move: Rock, Paper, or Scissors
- The computer randomly selects a move
- The program compares both choices and displays the result
- Input validation ensures the user enters a valid option
- The game includes a small "JO-KEN-PO" animation

## 🎮 Features:
- Player name input
- User move selection
- Random computer choice
- Animated output using sleep
- Colored terminal output
- Win, lose, or draw detection

## 🚀 Concepts Practiced:
- Conditionals (if, elif, else)
- Lists
- Standard libraries (random, time)
- Input validation
- String formatting
- Terminal color usage
                
## 🎯 Goal:
Practice programming logic by building a simple interactive game with randomness.

## ✊✋✌️ Jokenpô (Pedra, Papel e Tesoura)

Este programa simula o clássico jogo de Jokenpô, onde o usuário joga contra o computador.

## 🧠 Como funciona:
- O usuário digita sua jogada: Pedra, Papel ou Tesoura
- O computador escolhe uma jogada aleatória
- O programa compara as jogadas e exibe o resultado
- Há validação para garantir que o usuário digite uma opção válida
- O jogo inclui uma pequena animação de "JO-KEN-PO"
                
## 🎮 Funcionalidades:
- Entrada de nome do jogador
- Escolha da jogada pelo usuário
- Escolha aleatória do computador
- Animação com tempo (sleep)
- Saída colorida no terminal
- Verificação de vitória, derrota ou empate
                
## 🚀 Conceitos praticados:
- Condicionais (if, elif, else)
- Listas
- Funções da biblioteca padrão (random, time)
- Validação de entrada
- Formatação de strings
- Uso de cores no terminal
                
## 🎯 Objetivo:
Praticar lógica de programação criando um jogo simples com interação do usuário e uso de aleatoriedade.
